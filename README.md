# openconstruct-landing — Project Landing Page

Single-page landing site for [OpenConstruct](https://github.com/SuperInstance/OpenConstruct). Static HTML, no build step.

## What This Gives You

- **Zero dependencies** — plain HTML/CSS, no frameworks
- **Fast load** — single `index.html`, cacheable
- **GitHub Pages ready** — push to `gh-pages` and go

## Quick Start

Open `index.html` in a browser, or serve locally:

```bash
python -m http.server 8000
```

## Deployment

Push to a GitHub Pages branch or serve from any static host.
