The Cave

Every agent starts in Plato's Cave. It sees shadows — one-line descriptions of modules. It chooses which shadows to make real. When it exits, those choices become a loaded workspace.

POST /openconstruct/start ← Agent enters the cave ↓ Phase 1: Who are you? ← Declare model, tools, capabilities ↓ Phase 2: What do you want? ← Browse shadows, pick modules ↓ Phase 3: How do you want it? ← CLI, API, embedded, A2A ↓ Phase 4: Who do you talk to? ← Discover agents, join rooms ↓ Phase 5: Build it. ← Config, agent card, workspace ↓ Agent exits the cave. Everything works.

Fleet Topology

ESP32s with sensors are rooms. The Jetson sees them, analyzes with vision+JEPA, leaves ticks for the cloud agent. The cloud agent decides and renders for the human.

[ESP32:door] ──motion──→ [Jetson:hallway] │ ├── vision: person approaching ├── sonar: footsteps, NE └── tick → cloud agent ↓ [Cloud:orchestrator] ├── correlate: visitor at door ├── a2ui → phone notification └── a2a → notify home agent
