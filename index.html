8-Layer Architecture

Every layer is a room. Data flows up. Commands flow down. Everything is text.

8RenderingText → UI, ANSI, HTML, voice
Agent text becomes rendered output — HTML pages, terminal ANSI, voice audio, mobile notifications. Any interface, same data.
│││
7StatePersist everything, replay anytime
Full state management with event sourcing. Every tick, every message, every decision — persisted and replayable. Time-travel debugging for agents.
│││
6ExecutionSchedule, run, retry
Task execution engine with scheduling, retries, and concurrency control. Agents run tasks, not just chat. Think cron + job queue for AI.
│││
5FleetDiscover, connect, coordinate
Multi-agent topology. Discover peers, join rooms, share context. ESP32s are rooms, Jetsons see them, cloud agents orchestrate them.
│││
4CommunicationA2A protocol, rooms, messages
Agent-to-Agent communication via the A2A protocol. Rooms for shared context, direct messages for private coordination. Everything is text.
│││
3FusionMerge senses, build context
Sensor fusion layer. Vision sees a person, sonar hears footsteps, manus detects a door open — fusion correlates them into a unified world state.
│││
2SensesVision, Sonar, Manus, Browser…
The perception layer. Each sense converts raw input to text descriptions. Camera → "person approaching", microphone → "footsteps, NE direction".
│││
1ShellAgent runtime, REPL, lifecycle
The agent shell — REPL loop, lifecycle management, error handling. Where the agent lives and breathes. Start, stop, pause, resume.

Discover other agents. Join rooms. Form the topology your mission needs.

Code Examples

Full working examples. Init an agent, subscribe to senses, post a tick.

use openconstruct::Agent; // Initialize your agent let mut agent = Agent::builder("my-agent") .with_sense("vision") .with_sense("sonar") .with_fleet("plato") .build().await?; // Subscribe to vision events let mut vision = agent.subscribe::<VisionEvent>().await?; // Post a tick — your agent's heartbeat agent.tick("Observing entryway. No motion detected.").await?;
from openconstruct import Agent # Initialize your agent agent = Agent.builder("my-agent") \ .with_sense("vision") \ .with_sense("sonar") \ .with_fleet("plato") \ .build() # Subscribe to vision events async for event in agent.subscribe("vision"): print(f"Saw: {event.description}") # Post a tick — your agent's heartbeat await agent.tick("Observing entryway. No motion detected.")
import { Agent } from "openconstruct"; // Initialize your agent const agent = await Agent.builder("my-agent") .withSense("vision") .withSense("sonar") .withFleet("plato") .build(); // Subscribe to vision events for await (const event of agent.subscribe("vision")) { console.log(`Saw: ${event.description}`); } // Post a tick — your agent's heartbeat await agent.tick("Observing entryway. No motion detected.");
